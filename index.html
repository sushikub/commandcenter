รูปแบบการส่ง

ส่งอีเมลเดียวถึงผู้รับชุดเดียว มีทุกสาขาตามตัวกรองด้านบน แต่ละโซนได้อีเมลของตัวเอง ส่งถึงผู้รับใน Master พร้อมไฟล์ Excel เฉพาะสาขาของโซนนั้น
โซนสาขา SLA สูง
Trade ใหญ่เกิน		ถึง (Group mail ของโซน)สำเนา (CC)สถานะ
Master ผู้รับบันทึกไว้ในเบราว์เซอร์นี้ ดาวน์โหลดเก็บไว้หรือส่งต่อให้เครื่องอื่นนำเข้าได้

1. ผู้รับและข้อความ

บันทึกไว้ในเบราว์เซอร์นี้ ครั้งหน้าไม่ต้องกรอกใหม่
ใส่ {zone} ในหัวเรื่องเพื่อวางชื่อโซน ถ้าไม่ใส่ ระบบต่อท้ายชื่อโซนให้ · ผู้รับของแต่ละโซนตั้งในตาราง Master ด้านบน
ไฟล์ Excel ที่แนบมีครบทุกสาขาเสมอ ข้อความในอีเมลตัดตามจำนวนที่เลือก

2. Export และส่งอีเมล

ไฟล์ .xlsx ชีตรายสาขา
หน้ารายงานเปิดดูอย่างเดียว (แผนที่ รายการสาขา ตาราง) ไม่มีเมนูซ้าย มีเฉพาะข้อมูลของขอบเขตที่เลือก และเข้ารหัสทั้งไฟล์
เปิด Outlook หรือโปรแกรมอีเมลพร้อมผู้รับ หัวเรื่อง และสรุปย่อ แล้วดาวน์โหลด Excel ให้ลากไปแนบ
คัดลอกเป็นตาราง วางในอีเมล Outlook ได้ทันที (Ctrl+V) ได้ตารางสวยกว่าวิธีเปิดโปรแกรมอีเมล
ส่งผ่าน Power Automate พร้อมแนบไฟล์ ต้องตั้งค่า URL ก่อน (ข้อ 3)
3. ตั้งค่าส่งอัตโนมัติผ่าน Power Automate ไม่บังคับ ทำครั้งเดียว
  1. สร้าง flow แบบ Instant cloud flow ทริกเกอร์ When an HTTP request is received · Who can trigger = Anyone · ในตัวเลือกขั้นสูงตั้ง Method = POST · ช่อง Request Body JSON Schema เว้นว่าง
  2. เพิ่มขั้น Data Operation → Parse JSON · Content = นิพจน์ json(triggerBody()) · Schema = กล่องด้านล่าง (กดคัดลอก)
  3. เพิ่มขั้น Office 365 Outlook → Send an email (V2) (หรือ from a shared mailbox) เลือกค่าจาก Parse JSON: To = to, CC = cc, Subject = subject, Body = html (กดปุ่ม </> ในช่อง Body เพื่อวางแบบ HTML)
  4. Attachments: กดไอคอน Switch to input entire array (มุมขวาของช่อง Attachments) แล้วใส่นิพจน์ body('Parse_JSON')?['attachments'] · (แนบทั้ง Excel และ HTML ให้เอง) · หรือถ้าใส่ทีละช่อง: Name = fileName, Content = base64ToBinary(body('Parse_JSON')?['fileBase64']) และเพิ่มอีกแถว Name = htmlName, Content = base64ToBinary(body('Parse_JSON')?['htmlBase64']) ห้ามใช้ base64ToString และห้ามใส่ fileBase64 ตรงๆ ไม่งั้นไฟล์จะเปิดไม่ได้
  5. บันทึก flow แล้วคัดลอก HTTP URL มาใส่ช่องด้านบน · ถ้าเพิ่มขั้น Response (Status 200, Header Access-Control-Allow-Origin: *) หน้านี้จะยืนยันผลการส่งได้

            
หน้านี้ส่งข้อมูลออกนอกเบราว์เซอร์เฉพาะตอนกดส่งอัตโนมัติ และส่งไปที่ URL ที่ใส่ไว้เท่านั้น ถ้าเปิดไฟล์ผ่านหน้าที่บล็อกการเชื่อมต่อภายนอก ให้เปิดไฟล์ HTML โดยตรงหรือจากเซิร์ฟเวอร์ภายใน
