# Rider Command Center · 7-Delivery

เว็บแอปไฟล์เดียว (`index.html`) สำหรับติดตามไรเดอร์และวิเคราะห์พื้นที่จัดส่งของสาขา 7-Eleven

## เมนู
- **ภาพรวมไรเดอร์** – ไรเดอร์ออนไลน์/ออฟไลน์ สาขาที่ขาด ครบ เกิน แยก 13 พื้นที่และจังหวัด
- **พื้นที่จัดส่ง** – เทรดแอเรียจากไฟล์ หมุดลูกค้า 3 ระดับ (นานๆ ที / ปานกลาง / ประจำ) และคำแนะนำตัดพื้นที่
  - **จัดการข้อมูล** – อัปโหลดไฟล์สาขา เทรดแอเรีย หมุดลูกค้า สถานะไรเดอร์ และตาราง 13 พื้นที่

## วิธีใช้
เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ (เช่น GitHub Pages หรือ `python -m http.server`) เพื่อให้แผนที่ OpenStreetMap โหลดได้
ข้อมูลที่อัปโหลดอ่านในเบราว์เซอร์เท่านั้น ไม่ถูกส่งออกไปที่ใด

## รูปแบบไฟล์เทรดแอเรีย
`store_code, geometry, created_at` – geometry เป็นข้อความ GeoJSON (Polygon/MultiPolygon) ดูตัวอย่างใน `samples/`
